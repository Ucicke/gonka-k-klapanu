# Гонка к клапану

Мини-прототип игры для джема на TypeScript и нативном Canvas 2D: семь тромбов соревнуются в кровотоке, кто первым доберётся до клапана.

## Запуск

В Windows можно запустить локальный сервер одной командой:

```powershell
.\start-local.ps1
```

Для запуска нужен Node.js версии `^20.19.0` или `>=22.12.0`.

При первом запуске скрипт установит зависимости из `package-lock.json`. Чтобы выбрать порт и сразу открыть игру в браузере:

```powershell
.\start-local.ps1 -Port 4173 -OpenBrowser
```

Сервер доступен только на этом компьютере по адресу `http://127.0.0.1:5173/` (или выбранному порту). Остановить его можно сочетанием `Ctrl+C`.

Запуск вручную:

```sh
npm install
npm run dev
```

## Команды

- `npm run dev` — запустить локальный сервер разработки.
- `start-local.ps1` — запуск локального сервера в Windows; при необходимости устанавливает зависимости.
- `npm run build` — проверить типы и собрать игру в `dist/`.
- `npm run preview` — локально посмотреть production-сборку.

## Управление

- `W` / `↑` — газ.
- `S` / `↓` — тормоз.
- `A` / `D` или `←` / `→` — руль.
- `Пробел` — бросить тромбовый сгусток в соперника впереди. Если рядом никого нет, запас превращается в рывок.
- `Enter` — начать заезд; после финиша `Enter` или `R` запускает новый.

Трасса длиной 36 000 игровых метров проходит через повороты и заканчивается мембраной клапана. Заезд занимает около двух минут; перед стартом идёт отсчёт, а за соперником можно поймать слипстрим и ускориться.

Утолщённые холестериновые бляшки вызывают участки атеросклеротического стеноза и реально сужают проезд. Эритроциты повышают массу и вязкость тромба: он медленнее разгоняется и едет, зато сильнее таранит. Тромбоциты дают заряд для тромбового броска. Плазмин облегчает сгусток, ускоряет поток и может растворить встреченную впереди фибриновую сетку. Лейкоциты и фибриновые сети — опасности, съезд за край замедляет.
